# OpenAlbert

Персональный Telegram-бот на Go с долговременной памятью, фоновыми задачами,
браузерными инструментами, распознаванием голосовых сообщений и собственным
Ubuntu-компьютером с доступом по SSH и `sudo` без пароля.
LLM подключается через внешний OpenAI-совместимый API.

- [Локальная разработка и тесты](docs/development.md): `compose.local.yaml` собирает код из checkout.
- [Запуск готовых образов и публикация](docs/deployment.md): `compose.yaml` получает образы из GHCR.
- [Архитектура и документация](docs/README.md).

GitHub Actions запускает проверки на pull request и push в `master`. После успешных
проверок `master` публикуются образы для Linux AMD64 и ARM64, включая Raspberry Pi 5
с 64-битной ОС. Фактическая скорость локального распознавания речи на Pi ещё требует замеров.

Рабочие `.env`, ключи, история, вложения и память находятся вне Git и образов.
