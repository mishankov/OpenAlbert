# Альберт для macOS

Нативное приложение на SwiftUI и AppKit, macOS 14 или новее. Один разговор,
поручения, личная память и файлы. Для обновлений подключён Sparkle 2.10.0.

## Сборка и запуск

Из корня репозитория на Mac с установленными Xcode Command Line Tools:

```sh
apps/macos/build-app.sh
python3 apps/macos/desktop_vm.py run
```

Скрипт создаёт release-сборку для архитектуры текущего Mac и подписывает её
локальной ad-hoc подписью. Автообновление включается в релизной сборке с постоянной
подписью приложения и отдельным ключом Ed25519. Настройка и выпуск описаны в
[обновлениях macOS](../../docs/macos-updates.md). Developer ID, нотариализация и
универсальный бинарник пока не настроены.

Локальная разработка и desktop-проверки используют отдельную macOS VM в Tart,
как в Polka. Однократно выполните `python3 apps/macos/desktop_vm.py setup`,
затем `doctor`. Команда `run` открывает приложение внутри гостевой macOS.
Сборка выполняется на хосте; clipboard, микрофон и личный профиль хоста
не передаются. Подробности — в [руководстве VM](../../docs/macos-development-vm.md).

В первом окне подключения укажи HTTP- или HTTPS-адрес сервера и `DESKTOP_API_TOKEN`.
Для Pi в локальной сети можно указать `http://192.168.1.31:8080`.
Токен сохраняется в Keychain, URL — в настройках приложения. Настройка API и удалённого доступа:
[docs/desktop.md](../../docs/desktop.md). Форматы запросов:
[docs/desktop-api.md](../../docs/desktop-api.md).

Черновик, идентификатор повторной отправки и загруженная история хранятся в
`~/Library/Application Support/Albert/` с правами доступа только владельцу.
Новый текст, набранный во время отправки, сохраняется. После обрыва соединения
клиент догружает историю до уже известных сообщений.

## Клавиатура

Все команды доступны в меню приложения и подсказках кнопок.

| Действие | Сочетание |
| --- | --- |
| Разговор / поручения / память / файлы | ⌘1 / ⌘2 / ⌘3 / ⌘4 |
| Показать разделы | ⌘\\ |
| Отправить сообщение | Enter (также ⌘Return) |
| Обсудить выбранное поручение | ⌘Return |
| Новая строка в сообщении | Shift+Enter |
| Прикрепить файл | ⌘O |
| Открыть выбранное вложение черновика | ⌘⇧O |
| Убрать выбранное вложение черновика | ⌘Delete |
| Начать / завершить запись голоса | ⌘⇧R |
| Прослушать / остановить голосовой черновик | ⌘⇧P |
| Остановить работу | ⌘. |
| Повторить отправку или обновление | ⌘R |
| Сохранить выбранный файл | ⌘S |
| Подключение | ⌘, |
| Обновления | ⌘⇧U |
| Предыдущие сообщения | ⌃⌘↑ |
| Закрыть просмотр, вернуться или убрать контекст | Escape |

⌘↑ сохраняет стандартную навигацию внутри редактора. При выборе изображения
стрелки переключают изображения. Команды не отправляют сообщения во время IME
composition и при удержании клавиши. Диалоги блокируют команды основного окна.

## Проверки

```sh
swift test --package-path apps/macos --filter AlbertCoreTests
python3 -m unittest discover -s apps/macos -p 'test_*.py' -v
python3 tools/checks/check-contract.py
python3 apps/macos/desktop_vm.py test
python3 apps/macos/desktop_vm.py smoke
python3 apps/macos/desktop_vm.py screenshots
```

Тесты проверяют HTTP-клиент, черновик и повторную отправку, восстановление после
отключения, настоящее AppKit-окно, меню и текстовый редактор. Сквозной тест
поднимает Go API с временными данными и не обращается к Telegram или модели.
Smoke использует временное хранилище, не читает токен и не меняет пользовательский
черновик. Результаты и скриншоты возвращаются из VM на хост. Локальный запуск
AppKit-тестов и smoke непосредственно на хосте запрещён по умолчанию.
Отказ VM не переключает тесты на хост. Полный сценарий запускается из корня через
`task test:macos`; логи сохраняются в `reports/local/`.

Проверки голосовых используют подменяемое устройство и AAC-файлы с синтетической
тишиной, не запрашивают доступ к настоящему микрофону и не проигрывают звук.
