# Необязательный шаблон компьютера пользователя

Эти файлы не входят в основной Compose, Bake или публикацию образов Альберта.
Пользователь копирует каталог в отдельное место и один раз собирает окружение
у себя. `compose.yaml` управляет отдельным проектом, `app.compose.yaml` подключает
к нему только приложение. Обновления Альберта этот проект не затрагивают.

Создание, подключение существующей машины, безопасный перенос прежнего контейнера
и резервирование: [руководство компьютера](../../docs/computer.md) в репозитории.

Backend подключается по SSH через `apps/backend/internal/computer`.
`task test:computer` из checkout проверяет адаптер и независимость жизненного цикла
на одноразовых контейнерах. Это явная тестовая сборка, не часть каталога образов.
