# VictoriaLogs

Хранилище структурированных логов использует готовый upstream-образ.
Собственного исполняемого кода и отдельного Dockerfile у компонента нет.

Версия образа, retention, поля Splunk, порты и постоянный том заданы
в `deploy/compose*.yaml`, чтобы release Compose оставался самостоятельным.
Логи поступают через соседний [log-gateway](../log-gateway/).

См. [формат событий и диагностику](../../docs/observability.md).
