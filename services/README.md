# Сервисы

Здесь находятся необязательные вспомогательные сервисы, обслуживающие backend.
Каждая папка содержит исходники, Dockerfile и файлы своего компонента.

| Компонент | Содержимое |
| --- | --- |
| [backup](backup/) | Планировщик зашифрованных S3-копий, онлайн-снимок SQLite (`VACUUM INTO`) без простоя и без Docker socket, ротация, восстановление и статус для backend (профиль `backup`) |
| [computer](computer/) | Необязательный шаблон отдельного пользовательского окружения (не входит в основной Compose и релизные образы) |
| [stt](stt/) | Go HTTP-прокси, NeMo-Speech.cpp, запуск локального распознавания речи (профиль `local-stt`) |
| [tts](tts/) | HTTP-сервис синтеза речи Piper и преобразования в Ogg/Opus через FFmpeg (профиль `local-tts`) |

Совместный запуск, версии четырёх готовых образов (`openalbert`, `stt`, `tts`, `backup`),
подключения, порты и тома задаются в [deploy](../deploy/). Основное приложение
`openalbert` не требует внешних серверов БД, очередей, объектного хранилища или
сбора логов: при пустом `COMPOSE_PROFILES` запускается единственный контейнер `openalbert`.
`task check` проверяет соответствие `deploy/compose.local.yaml` и `deploy/compose.yaml`.
