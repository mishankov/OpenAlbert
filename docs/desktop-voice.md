# Голосовые сообщения macOS

Голосовое — вложение в том же единственном разговоре. Сначала запись, затем прослушивание и явная отправка; текст и остальные вложения остаются в черновике.

- Запись: M4A / AAC, mono, максимум 5 минут и 20 MiB. Доступ к микрофону запрашивается только по команде пользователя.
- ⌘⇧R начинает/завершает запись; ⌘⇧P включает/останавливает прослушивание готового черновика. Escape отменяет запись/убирает готовую запись с сохранением текста. Enter отправляет готовое сообщение. Во время записи отправка недоступна.
- Готовый звук сохраняется приватно вместе с черновиком, переживает перезапуск и ошибку сети. При выходе активная запись завершается и сохраняется. Отказ в разрешении и ошибка устройства оставляют текст нетронутым. Отменённый запрос разрешения не начинает запись позднее.
- POST /api/v1/attachments: multipart file, имя voice-<UUID>.m4a, Content-Type audio/mp4. Ответ — существующий Attachment. Затем обычный POST /api/v1/messages с attachment_ids и текстом. Успешно загруженное вложение повторно не загружается при повторе POST messages; client_message_id сохраняется для того же сообщения.
- API распознаёт M4A как audio/mp4 и передаёт вложение в существующий STT. Реальная длительность проверяется на сервере при декодировании. Аудиобайты и приватные рассуждения не попадают в JSON истории.
- В композере компактная кнопка микрофона; во время записи — прошедшее время и остановка/отмена; готовая запись — воспроизведение, длительность и удаление. Без декоративной волны. В истории аудио доступно для воспроизведения через авторизованную загрузку.
- Удаление готового звука, отправка, повтор и клавиатура используют общие действия и одинаковые ограничения busy/modal/IME/key repeat. Проверки устройства и разрешений тестируются через подменяемый драйвер, без доступа к реальному микрофону.
