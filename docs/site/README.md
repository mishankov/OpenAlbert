# Сайт архитектурной документации

Сайт собирается из Markdown в [docs](../README.md). Разделы, поиск и схемы используют эти файлы; отдельной копии содержимого в исходниках сайта нет. Замечания оставляются встроенными средствами T3 Code.

## Запуск

Все команды выполняются из папки `docs`, с Node.js 22 или новее:

```sh
cd docs
npm install
npm run dev
```

Адрес: <http://localhost:4173>. При необходимости порт задаётся переменной `PORT`. После изменения Markdown, схем или файлов интерфейса сервер пересобирает сайт; обнови страницу для просмотра изменений.

## Статическая сборка

```sh
npm run build
```

Результат находится в `docs/site/dist` относительно корня репозитория и может обслуживаться обычным статическим HTTP-сервером. Переходы используют hash-маршруты и не требуют настройки серверного fallback. В сборке находятся все схемы, Markdown-исходники и поисковые данные; внешние CDN не используются.

Исходники сайта, скрипты, `package.json`, lock-файл, зависимости, конфигурация Playwright, тесты и их результаты также находятся внутри `docs`. Сборка копирует только материалы документации и файлы интерфейса; инструменты разработки и зависимости в опубликованный результат не входят.

## Управление с клавиатуры

- `⌘K` на macOS или `Ctrl+K` на других платформах — открыть поиск. Комбинация показана на кнопке поиска; сайт перехватывает привычную браузерную команду поиска в адресной строке, пока страница активна.
- В поиске `↑` / `↓` выбирают результат, `Enter` открывает его, `Esc` закрывает диалог. Введённый запрос сохраняется при закрытии.
- На сфокусированной схеме `Enter` открывает просмотрщик. Начальный размер вычисляется из SVG viewBox и доступной области: схема максимально вписывается в окно. В нём `+` / `−` меняют масштаб, `0` снова вписывает схему, `W` разворачивает её по ширине, `Esc` закрывает окно.
- `Tab` последовательно перемещает фокус по ссылкам и кнопкам. Диалоги удерживают фокус и возвращают его после закрытия.

Кнопки и сочетания вызывают общие действия. Команды учитывают открытые диалоги, недоступные кнопки, IME и повтор клавиш. Сочетания определяются по физическому коду клавиши, включая неанглийскую раскладку. Внутренних конфликтов сочетаний нет; остальные команды браузера сохраняются.

При ширине окна до 1360 px, в том числе в панели T3 Code, меню разделов и оглавление открываются из верхней панели, а текст использует доступную ширину. На широком экране остаётся постоянная боковая навигация.

## Проверка

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

Модульные тесты проверяют сборку документов, внутренние ссылки и клавиатурные команды. Playwright проверяет все страницы, узкую раскладку, поиск, IME, повторы клавиш и полный сценарий просмотра схем. Для уже установленного Chromium можно задать путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Замечания к результату оставляются в предпросмотре T3 Code.
